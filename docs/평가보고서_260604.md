## 2. 기술 평가

### 2-1. 기술 스택 적정성 ★★★★★

HTML/CSS/JS 순수 정적 스택을 선택한 것은 다음 이유에서 최적의 판단이었다.

- 빌드 도구 없이 GitHub Pages에 즉시 배포 가능
- 외부 프레임워크 의존성 없어 유지보수 단순
- 초보자도 코드를 직접 읽고 수정하기 쉬운 구조
- 페이지 로드 속도 최적

### 2-2. CSS 설계 ★★★★☆

- CSS 변수(Custom Properties)를 활용한 **3컬러 시스템** 체계적 정의
  - `--main` (Sky Blue), `--point` (Lavender), `--accent` (Coral Pink)
  - 라이트/다크 모드 변수 분리 구조
- `[data-theme="dark"]` 단일 선택자로 다크모드 완전 제어
- 하위호환 별칭(`--primary`, `--secondary`) 처리로 리팩토링 안전성 확보
- **개선 여지**: 일부 inline style이 남아있음 (웨이브 SVG path fill)

### 2-3. JavaScript 구조 ★★★★☆

- 즉시 실행 함수(IIFE) 패턴으로 전역 오염 최소화
- `IntersectionObserver`를 활용한 효율적 스크롤 애니메이션
- Canvas API로 수채화 오브 효과 직접 구현 (외부 라이브러리 미사용)
- `localStorage` + `matchMedia`를 조합한 다크모드 토글 (UX 완성도 높음)
- **개선 여지**: 이벤트 리스너 정리(cleanup) 로직 부재

### 2-4. 디자인 완성도 ★★★★☆

- 그라디언트 웨이브 섹션 디바이더로 시각적 흐름 자연스럽게 구성
- 컬러 시스템이 히어로 배경, 버튼, 카드 호버, Canvas 오브까지 일관성 있게 적용
- **개선 여지**:
  - 스카이블루(#0EA5E9)의 흰 배경 대비율 3.9:1 — 본문 텍스트가 아닌 버튼·대형 요소 한정 사용 권장
  - 모바일에서 히어로 오브 렌더링 성능 모니터링 필요

### 2-5. 접근성 & SEO ★★★★☆

- Open Graph 메타태그 완비로 소셜 공유 최적화
- `aria-label` 속성을 주요 버튼에 적용
- 시맨틱 HTML 태그(`<nav>`, `<section>`, `<footer>`) 사용
- **개선 여지**:
  - 이미지 alt 텍스트 구체화 필요
  - `<meta name="description">` 일반 메타태그 별도 추가 권장

## 3. 작업 프로세스 평가

### 잘된 점
- 콘텐츠 입력 → 디자인 → 기능 구현 → 최적화 순서로 체계적 진행
- 변경사항마다 즉시 커밋·푸시하여 작업 이력을 명확히 추적
- 사용자 선택을 반영한 인터랙티브한 디자인 결정 프로세스 (선택지 제공)
- 컬러 시스템을 중반에 재정비하여 이후 작업의 일관성 확보

### 아쉬운 점
- 별 반짝임 효과 → 수채화 오브 교체 시 가시성 검토를 사전에 충분히 하지 못함
- 컬러 시스템을 처음부터 정의하지 않고 중반에 수립하여 일부 재작업 발생
- 카카오 OG 이미지 캐시로 인해 변경 확인에 시간이 소요됨
