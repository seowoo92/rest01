## 1. 작업 개요

GitHub 빈 리포지토리(`rest01`)에서 시작하여 개인 이력서 포트폴리오 웹사이트를 하루 만에 기획·개발·배포까지 완료하였다. 순수 HTML/CSS/JavaScript 스택을 사용해 별도 빌드 도구 없이 GitHub Pages에 자동 배포되는 구조를 구성하였다.

---

## 2. 작업 이력

### 2-1. 환경 세팅
- GitHub 리포지토리 클론
- GitHub Actions 워크플로우(`.github/workflows/deploy.yml`) 작성
  - `main` 브랜치 push 시 자동 빌드·배포
- 기술 스택 결정: **HTML5 / CSS3 / Vanilla JavaScript** (정적 사이트)

### 2-2. 기본 구조 구축
- `index.html` — 6개 섹션 단일 페이지 구조 설계
  - 네비게이션, 히어로, 소개, 스킬, 경력, 학력 → 이후 수상·자격증으로 재구성
- `style.css` — CSS 변수 시스템, 반응형 레이아웃, 컴포넌트 스타일
- `script.js` — 스크롤 감지, 활성 링크, 페이드인 애니메이션, 폼 처리

### 2-3. 콘텐츠 입력
| 섹션 | 입력 내용 |
|------|-----------|
| 히어로 | 이름(김서우), 직책, 태그라인, SNS 링크 |
| 소개 | 자기소개문, 기본 인적사항(생년월일·거주지·연락처·이메일) |
| 스킬 | AI 도구(ChatGPT·Claude), 협업/생산성(GitHub·Notion), 문서작성(Word·Excel·PowerPoint), 언어(영어 Intermediate) |
| 경력 | Courtyard by Marriott(2022), ComexPlans(2019~2022), KTcs(2017~2018) |
| 학력 | 호서대학교 항공서비스전공, 백석고등학교 |
| 수상 | 제5회 K-Digital Training 해커톤 최우수상(고용노동부 장관상) |
| 자격증 | 네트워크 관리사 2급, 리눅스마스터 2급, 컴퓨터활용능력 2급, 자동차 운전면허 2종 |

### 2-4. 디자인 고도화
- **그라디언트 웨이브 디자인** 적용
  - 히어로: 보라→파랑→하늘 애니메이션 그라디언트 배경 (`gradientShift` 키프레임)
  - 섹션 간 물결형 SVG 디바이더 (5곳, 교대 방향)
  - 버튼·카드 호버에 그라디언트 포인트 적용
- **Canvas 히어로 효과**
  - 1차: 별 반짝임(90개, 너무 작아 가시성 부족)
  - 2차: 수채화 그라디언트 오브로 교체 (11개, 60~170px, 느린 부유 효과)
- **프로필 사진**: 160px → 280px 확대

### 2-5. 컬러 시스템 수립
- 1차 시도: Royal Blue + Pink + Yellow → 노란색 부조화로 변경
- 최종 확정:

| 구분 | 명칭 | HEX | CSS 변수 |
|------|------|-----|---------|
| 메인 | Sky Blue | `#0EA5E9` | `--main` |
| 포인트 | Lavender | `#A78BFA` | `--point` |
| 강조 | Coral Pink | `#FB7185` | `--accent` |

- CSS 변수 체계 정비: `--main`, `--point`, `--accent` + `-hover`, `-soft` 변형
- 기존 코드 하위호환을 위해 `--primary`, `--secondary` 별칭 유지

### 2-6. 다크모드 구현
- `[data-theme="dark"]` CSS 오버라이드 블록 작성
- 다크모드 색상: `--main: #38BDF8`, `--point: #C4B5FD`, `--accent: #FDA4AF`
- 배경: `#0f172a` / 서피스: `#1e293b`
- 네비게이션 우측 🌙 / ☀️ 토글 버튼 추가
- `localStorage`에 사용자 선택 저장 (새로고침 유지)
- 시스템 다크모드 자동 감지 (`prefers-color-scheme`)

### 2-7. OG 이미지 & 파비콘
- Python(Pillow) 스크립트(`generate_og.py`)로 OG 이미지 생성
  - 규격: 1200 × 630px
  - 다크블루 배경 + 수채화 오브 장식 + 그라디언트 사이드바 + 하단 컬러 라인
  - 텍스트: "Profile" / "김서우" / "노코드 / AI툴 활용 · 서비스기획자"
- Open Graph 메타태그 6종 삽입 (`og:url`, `og:title`, `og:description`, `og:type`, `og:image`, `og:site_name`)
- 파비콘: `favicon.ico` (16×16, 32×32 멀티 사이즈)
